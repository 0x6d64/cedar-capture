# Documentation index

| File | What it is |
| --- | --- |
| `plan/project-plan.md` | Overview, flow diagram, schedule, risks, open decisions |

| `gates.md` | Go/no-go gates `GATE-*` and thresholds |
| `decisions-log.md` | Research decisions `DEC-*` with evidence status |
| `adr/` | Accepted architecture decisions (ADRs) |
| `session-format.md` | Specification of the session file |
| `architecture.md` | Components, data flow, interfaces |
| `testing/test-protocol.md` | The ground-truth recording and question set |
| `results/RESULTS-LOG.md` | Where every measurement goes |
| `agent-workflow.md` | How humans and coding agents share the work |
| `skeleton-status.md` | What was and was not verified when this skeleton was generated |

ID families: `REQ` requirements, `DEC` decisions, `GATE` go/no-go checks, `STEP` work items, `ADR` accepted decisions.
Never reuse or renumber an ID.
