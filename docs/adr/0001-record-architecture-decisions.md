# ADR-0001: Record architecture decisions

- Status: Proposed
- Date: 2026-11-18
- Related: all

## Context

Several people and several coding agents will touch this repository, and many choices rest on weak evidence (see
`docs/decisions-log.md`). Without records, agents re-open settled questions or silently drift.

## Decision

Significant choices are recorded as ADRs in `docs/adr/`. The research behind them stays in `docs/decisions-log.md`.

## Consequences

Adding a dependency, changing a public interface or changing the session format needs an ADR first.
